# Verfeinert Documentation

This documentation describes the public `verfeinert` research framework for
quantum ansatz generation, analysis, evolution, and reproducible workflows.

## Sections

- `architecture/`: module boundaries, canonical JSON data contracts, execution
  policy, analyzer/evolver systems, visualization, ranking, and workflow
  design.
- `user/`: researcher-facing reproduction examples for CX-01 and MIXT-5G.
- `development/`: contributor validation and CI guidance.

The `docs/migration/` directory is release-preparation provenance kept in this
working tree. It is excluded from the first public repository.
