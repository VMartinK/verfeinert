## Public Contract Summary

Installation:

- Runtime install: `python -m pip install .` or a release wheel.
- Visualization extra: `python -m pip install ".[visualization]"`.
- Development extra: `python -m pip install -e ".[dev,visualization]"`.

CLI:

- `verfeinert validate <config>`;
- `verfeinert run <config>`;
- `verfeinert resume <checkpoint-or-run>`;
- `verfeinert inspect <artifact>`.

Workflow configuration:

- Scientific execution operations are `generate`, `analyze`, and `evolve`.
- Postprocessing operations include `ranking`, `pareto`, `comparison`,
  `export_csv`, `visualization`, and `report`.
- `workflow.campaign_type` is generic: `individual` or `evolutionary`.
- `generation.constraints`, analyzer materialization, execution policy,
  mutation policy, selection, stopping, checkpointing, observability,
  visualization, and reports are declarative config blocks.

Scientific execution:

- Structural cost remains inexpensive and record-based.
- Expressibility and trainability require `allow_expensive_metrics=true`.
- Automatic materialization also requires `allow_qnode_execution=true`.
- Explicit caller state callables take precedence over materialization.
- Unsupported materialization fails or skips truthfully; it is not silently
  interpreted.

Multiprocessing:

- Sequential mode is default.
- Candidate-level multiprocessing is explicit and requires
  `mode: multiprocessing`, `parallelize_candidates: true`, and positive
  `worker_count`.
- Worker/pickling/backend failures fail closed without sequential fallback.
- Order-dependent global sequential RNG policies are rejected under
  multiprocessing.

Checkpoint/resume:

- `workflow.checkpoint.enabled: true` writes
  `<output_root>/<run_id>/checkpoints/latest.json`.
- Resume checks run ID, compatibility fingerprint, scientifically relevant
  config, and artifact hashes.
- Completed generation/analysis stages are not rerun during checkpoint resume.

Artifacts:

- Canonical JSON contracts remain Candidate, StagedPackage, AnalysisResult,
  EvolutionRun, and ComparisonResult.
- CSVs, figures, reports, manifests, and traceability files are derived
  artifacts.
- Reports and visualization never compute or reinterpret scientific metrics.

Limitations:

- Global F/F2 visualization remains out of contract.
- Arbitrary external CSV ingestion is not a canonical workflow entry point.
- Materialization currently documents the PennyLane/default.qubit capability
  boundary; unsupported gates or parameter modes fail closed.
- Thesis-scale reproduction remains explicit opt-in; CI/external validation
  uses full-lite budgets.
