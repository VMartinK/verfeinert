## VIZ-032 Outcomes

- VIZ-032-01: Added visualization-only canonical objective labels and exported
  `PUBLICATION_TRAINABILITY_LABEL`, `PUBLICATION_EXPRESSIBILITY_LABEL`, and
  `publication_objective_label`. Default objective-space axes now use generic
  `T(H)` trainability and the canonical expressibility label unless explicit
  labels are supplied.
- VIZ-032-02: Added shared high-zorder, opaque publication legend treatment and
  applied it to affected Individual, Evolution, Global, and Pareto paths.
- VIZ-032-03: Moved E1/E2-E4 shared legends to the upper-right figure area,
  preserved top margin, and made them opaque/high-zorder.
- VIZ-032-04: E2/E3/E4 no longer draw subplot titles. Golden fixtures now
  prepare `Mean combined score`, `Mean expressibility`, `Mean trainability`,
  and `Mean structural cost` labels upstream. `MetricPanelSpec.title` remains
  public and positional-compatible.
- VIZ-032-05: E5 now maps threshold to color and generation order to increasing
  alpha. Added optional keyword-only `threshold_color`.
- VIZ-032-06: E6 uses equal-width/equal-height subplots, no suptitle, one title
  per axes, a figure-coordinate separator, and opaque/high-zorder legends.
- VIZ-032-07: Added keyword-only `ObjectiveSeries.score` for prepared aggregate
  campaign scores. G_C colors non-reference campaign frontiers by that prepared
  score, keeps baselines dashed/reference styled, keeps the global frontier
  black, emits a `DeprecationWarning` for legacy `score_points`, and draws no
  auxiliary score scatter.
- VIZ-032-08: Added deterministic grouped-bar headroom for global aggregate and
  contribution bar plots.
- VIZ-032-09: G_H left legend now explains bold numeric annotations as
  global-frontier member counts.
- VIZ-032-10: G_H right objective-space panel now includes a compact legend for
  rendered lineages in prepared order plus the global frontier.
- VIZ-032-11: Updated package version metadata, citation metadata, changelog,
  current visualization docs, current user docs, architecture notes, and the
  publication visualization example for v0.3.2.

## API Compatibility

- `ObjectiveSeries` keeps its legacy positional constructor order:
  `points`, `role`, `label`, `threshold`, `generation`, `source_id`.
- `ObjectiveSeries.score` is additive and keyword-only, validated as an
  optional finite float, and included naturally in `to_dict()`.
- `plot_frontier_evolution(..., threshold_color=...)` is additive and
  keyword-only.
- `plot_campaign_frontiers(..., score_points=...)` remains accepted for patch
  compatibility but is deprecated for G_C and no longer draws visible score
  points.
